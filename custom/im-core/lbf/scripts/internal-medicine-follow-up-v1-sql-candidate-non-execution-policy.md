# Internal Medicine Follow-Up V1 — SQL Candidate Non-Execution Policy

## 1. Purpose

This document defines the non-execution policy for any future executable SQL seed candidate related to the Internal Medicine Follow-Up V1 LBF layout.

This is a documentation-only policy.
